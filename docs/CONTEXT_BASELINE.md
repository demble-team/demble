## 图片的适用范围

- 首页介绍图说明用户闭环；架构图说明逻辑访问边界和审核主链路。图中方框不代表独立微服务或数据库选型。

- 图中的“原子提交”表示不能把不完整的写入宣称为成功；具体提交单元、冲突拆分及数据库事务方案仍由 OD-12 定义。
- 权限过滤覆盖所有来源、历史对象、附件、计数和检索结果；返回箭头不表示可以绕过鉴权。
- 反馈必须绑定确切版本，但可变外部 URL 不自动等同于内容快照；运行实例及无法冻结内容时的标注在 S2 定义。
